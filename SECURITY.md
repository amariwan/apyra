# Security Policy

## Reporting a vulnerability

Please **do not** open public issues for unpatched vulnerabilities.

Report security issues privately to the maintainers via the repository's
**Security** tab (GitHub private vulnerability reporting) or by email to the
maintainer. Include:

- A description of the issue and its impact
- Steps to reproduce
- Affected versions / packages
- Any suggested fix

You can expect an acknowledgement within a few working days and a coordinated
disclosure once a fix is available.

## Supported versions

Only the latest released version of each package is supported with security fixes.

## Scope

Security issues in `apyra-security`, `apyra-auth`, `apyra-fastapi`, and any
package that handles untrusted input are in scope. Issues in third-party
dependencies should be reported upstream.
