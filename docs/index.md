# Apyra

**FastAPI simplicity. Enterprise confidence.**

Apyra is a modular backend framework for Python 3.12+. It keeps FastAPI's direct programming model
while adding typed configuration, authentication, persistence, messaging, background work,
workflows, security, and observability as independently installable packages.
