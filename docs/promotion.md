# Promotion playbook (GitHub stars)

## Repo health (done)
- Public repo with clear description + 17 topics
- README with badges, quick start, star-history chart
- CI on push/PR (main), build + install sanity
- Labels: good first issue, help wanted, bug, enhancement, docs
- Discussions enabled
- v0.1.0 release + tag
- Own star added

## Next steps to actually get stars (manual, by you)

### 1. First 100 stars (artificial, close network)
- Send a short message to friends/colleagues: "I just open-sourced Apyra — a modular Python/FastAPI monorepo. If it looks useful, a ⭐ helps a lot: https://github.com/amariwan/apyra"
- Post on LinkedIn/Twitter/X with a 30s demo GIF.
- Ask in your office/Discord/Slack communities.

### 2. Show HN (high-impact)
Title: `Show HN: Apyra – modular Python/FastAPI monorepo (16 packages, uv workspace)`
First comment (post as maintainer):
> I built Apyra because I wanted FastAPI apps without a single giant framework — install only the pieces you need (core, db, auth, storage, cache, ai, …), each an independently publishable package under a shared PEP 420 namespace. Python ≥3.12, async-first, strict mypy+pyright. Examples included. Feedback welcome.

### 3. Reddit (self-promo days)
- r/Python, r/FastAPI, r/programming — use their weekly self-promo threads.
- Title: "I open-sourced Apyra: 16 composable Python packages for FastAPI apps"

### 4. Dev.to / Hashnode article
- Title idea: "Why I split my FastAPI starter into 16 packages (and how uv workspaces make it sane)"
- Include "⭐ https://github.com/amariwan/apyra" CTA in body.

### 5. Awesome lists PRs
- awesome-python, awesome-fastapi, awesome-uv — open PR adding Apyra under "Web Frameworks"/"Project Templates".

### 6. Product Hunt launch
- Tagline: "Modular Python framework for FastAPI — install only what you need"
- Launch day: PH + HN + Reddit same day for compounding traffic.

### 7. Social preview image
- Set a 1280×640 PNG in Repo Settings → Social preview (use a screenshot of README hero or generate one).
